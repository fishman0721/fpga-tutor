# FPGA 助学助手（fpga-tutor）

一个"AI 助学"开源项目：把你的 FPGA 工程自动变成一份**交互式单文件 HTML 学习页面**，
并围绕它持续讲解、练习、复习。页面可本地双击打开、离线使用，任务进度和测验成绩自动保存在浏览器里。

本项目以 **Skill（技能）** 形式分发：一段给 AI 的"说明书" + 一份页面模板，**零代码安装**。

## 它能做什么

- 🔍 自动扫描 FPGA 工程（Verilog / VHDL），提取模块层级、端口、信号
- 🧭 **可点击下钻的模块框图**：顶层 → 子模块 → 内部逻辑，逐层深入（面包屑 / Esc 返回，可缩放），信号以流动连线呈现
- 📄 生成单文件学习页面：工程概览、目录结构、模块卡片、端口信号表、关键代码逐段讲解
- ✅ 内置学习任务清单（从易到难，勾选进度本地保存）
- 🎯 内置小测验（带答案解析，自动判分）
- 📝 内置笔记区（输入自动保存）
- 💬 生成后可以继续和 AI 讨论，页面随讨论持续更新

## 效果预览

进入 [`examples/`](examples/) 下载示例页面，双击浏览器打开即可体验：

- [`ti_adc_sim`](examples/ti_adc_sim/fpga_study.html)：4 通道时间交织 ADC 行为模型（含下钻框图，仿真验证 100% 一致）

## 快速开始（普通用户）

1. 把本仓库的 `.agents/skills/fpga-tutor` 文件夹放进你的项目，或放到 AI 工具的用户技能目录（如 `~/.agents/skills/`）
2. 把 FPGA 工程目录设为 AI 工具的工作目录
3. 对 AI 说：**"用 fpga-tutor 技能分析这个工程，生成学习页面"**
4. 打开生成的 `study/fpga_study.html`，开始学习；随时回来继续讨论

## 兼容性

- 本技能遵循社区通用的 `SKILL.md` 格式（YAML frontmatter 元数据 + Markdown 正文），不依赖任何特定 AI 工具的专有功能
- 凡是支持 `.agents/skills`（项目级）或 `~/.agents/skills`（用户级）技能目录惯例的 AI 工具，都可以直接读取使用
- 纯"流程指引 + 模板"结构，任何智能体都能读懂并执行

## 目录结构

```
.
├── .agents/skills/fpga-tutor/    ← 技能本体
│   ├── SKILL.md                  ← 给 AI 的说明书（流程、规范、边界）
│   └── templates/
│       └── study-page-template.html  ← 学习页面模板（单文件、离线、零依赖）
├── examples/                     ← 生成的学习页面示例（见「效果预览」）
└── README.md
```

## 生成的学习页面长什么样

- 单文件 HTML，CSS/JS 全内嵌，**零外部依赖、零 CDN**，`file://` 双击即开，离线可用
- 深色主题，自动目录导航，手机/桌面自适应
- 九个章节：工程概览 / 目录结构 / 模块层级 / 端口与信号 / 关键代码解读 / 学习任务清单 / 小测验 / 术语表 / 我的笔记
