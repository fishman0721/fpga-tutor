① 工程概览

一句话功能：一个 4 通道时间交织 ADC（TI-ADC）的 行为级采样模型——用 SystemVerilog 忠实复刻 MATLAB 参考脚本 TI_ADC_v9.m（error_mode=4）的采样与误差注入逻辑，并由自验证测试平台确认与双精度参考实现完全一致。

工程类型：纯仿真验证工程（Vivado/xsim），无开发板、无约束文件；被测模型为不可综合的行为模型（real 运算 + $sin），学习重点是「模型如何工作」与「误差如何被测量」。配套 Python 工具（gen_reference.py / compare.py）构成双实现交叉验证闭环。

关键指标：总采样率 4 GSps（4 通道 × 1 GSps 时间交织）；14 位量化、±1 V 满量程、LSB ≈ 122.07 µV；相干采样单音输入 fin ≈ 189.27 MHz（M=3101 / N=65536）；每记录 65536 个样本。

各模块职责速览：

ti_adc_model（DUT · 被测模块）

src/ti_adc_model.sv · 行为级采样模型 · 不可综合（仿真专用）

职责：按 MATLAB 参考脚本 TI_ADC_v9.m（error_mode=4）忠实建模 4 通道时间交织 ADC：单音输入 → 逐通道注入时序偏移 / 失调 / 增益误差 → 14 位量化 → 逐样本输出。

关键端口：clk（4 GHz 采样时钟）、rst_n（同步复位）、adc_code[14:0]（量化码，±8192 ↔ ±1 V）、ch_id[1:0]（通道号）、valid（每样本一拍高电平）、idx[15:0]（样本序号）。

一句话解读：n[1:0] 决定通道归属（时间交织），n/FS + τ(ch) 决定采样时刻（偏移注入），(x + off)×gan 决定幅值误差，最后远离零四舍五入 + 饱和出码。

tb_ti_adc（主测试平台）

sim/tb_ti_adc.sv · 自验证 testbench

职责：产生 4 GHz 时钟与复位；收集 65536 个样本写入 sim_out/adc_out_codes.txt；逐通道用三种估计器反推注入的误差并与真值比对。

一句话解读：样本均值估失调、MAD 比值估增益、I/Q 正交解调 + atan2 估时序偏移——典型的「注入 → 提取」自校验闭环，每个估计量都对应一类 TI-ADC 失配。

tb_sin_check（能力探测）

职责：确认 Vivado xsim 支持 $sin / $atan2 / $floor / $ceil 等数学系统函数——行为模型的运行地基。

一句话解读：跑通即证明仿真器具备模型所需的 real 运算能力，为后续建模扫清障碍。

⑤ 关键代码解读

1. 时间交织：n[1:0] 决定通道归属

ch_id <= n[1:0];          // channel of this sample：序号低 2 位 = 通道号

交错的核心只有这一行：样本 n=0,4,8,… 归通道 0，n=1,5,9,… 归通道 1，依此类推。每个通道实际只以 1 GSps 采样，但四个通道轮流工作，整体输出就是 4 GSps——这正是时间交织（Time-Interleaved）的采样率倍增原理。

2. 相干采样：fin = FS·M/N，M 为什么是质数

localparam real FIN = FS * real'(M) / real'(N_SAMPLES); // 189.27 MHz

选择 fin = FS·M/N 且 M 与 N 互质，记录长度内恰好包含 M=3101 个整周期——FFT 分析时频谱不会泄漏。M 取质数（3101）还有一个隐藏好处：样本在 4 个通道间的分布完全均匀，任何通道都不会对输入信号欠采样。这是 ADC 测试中「相干采样」的标准做法。

3. 时序偏移注入：改的是「采样时刻」而不是「相位」

t_sample = real'(n)/FS + get_tau(n[1:0]);   // 理想时刻 + 通道偏移 τ
x_in     = A_IN * $sin(2.0*PI*FIN*t_sample);

时序偏移（skew）的本质是采样时钟沿的偏差：通道 1 晚采样 2 ps、通道 2 早 1.5 ps。注意 $sin 的参数是时间，所以 τ 直接平移采样点，等效改变信号相位 2π·fin·τ——这是对「真实采样时刻偏移」的正确建模，而不是简单给输出加一个相位常数。

4. 失调 + 增益注入：顺序与 MATLAB 严格一致

x_val = (x_in + get_off(n[1:0])) * get_gan(n[1:0]);

先加失调、再乘增益。这个顺序不是随便定的：它与 MATLAB 参考脚本逐行对应，任何调换都会改变等效误差，导致与参考对比失败。三个注入函数 get_off / get_gan / get_tau 用 case 语句把参数映射到通道号，参数化（OFF0..3 等）使得不改代码就能换一组误差。

5. 量化与饱和：远离零四舍五入 + 削顶

qval   = x_val / DELTA;        // 换算成 LSB 单位
qclamp = (qval >= 0.0) ? $floor(qval + 0.5) : $ceil(qval - 0.5);  // round half away from zero
if (qclamp >  FULL) qclamp =  FULL;   // 饱和到 ±8192（满量程码）
if (qclamp < -FULL) qclamp = -FULL;
adc_code <= int'(qclamp);

DELTA（LSB）= 2/2¹⁴ ≈ 122.07 µV，FULL = 8192。用 $floor/$ceil 实现「恰好 0.5 时远离零舍入」，与 MATLAB round 完全一致——这是 Verilog 与 Python 参考 100% 一致的关键之一。饱和削顶模拟真实 ADC 的输出范围限制。

6. 自验证：I/Q 正交解调估计时序偏移

cref = $cos(2.0*PI*FIN*tref);   sref = $sin(2.0*PI*FIN*tref);
sum_i[c] += v * cref;            sum_q[c] += v * sref;
tau_est[i] = $atan2(sum_i[i], sum_q[i]) / (2.0*PI*FIN);

把每个通道的采样值分别乘以同相（cos）与正交（sin）参考并累加，得到信号的复振幅：其辐角 = 2π·fin·τ，用 atan2 一步解出 τ。这是数字接收机里经典的载波相位估计思想。同理：样本均值 → 失调估计；MAD 比值 → 增益估计。三类失配各配一个估计器，形成完整的自校验闭环。
