① 工程概览

一句话功能：PC 通过串口（9600 bps）把一张 100×100 的 8bit 灰度图发给 FPGA，sobel_ctrl 用 Sobel 算子做边缘检测并阈值二值化（黑/白），结果一路由 vga 模块存入 RAM 后以 640×480 VGA 实时显示，另一路由 uart_tx 回传 PC——一个完整的「串口收发 + 图像处理 + 视频显示」学习工程。

硬件平台：野火「征途 Pro」开发板，Altera Cyclone IV E（EP4CE10F17C8N）；板载 50 MHz 晶振；VGA 接口；USB 转串口。

时钟方案：PLL（clk_gen）把 50 MHz 输入分出两个时钟：c0 = vga_clk 25 MHz（VGA 像素时钟）与 c1 = clk_50m（系统逻辑时钟）；复位 rst_n = sys_rst_n & locked——PLL 锁定后才释放复位，避免未锁定期间跑逻辑。

关键参数：串口 9600 bps；图片 100×100（LENGTH_P / WIDE_P = 100）；Sobel 阈值 THRESHOLD = 8'b000_011_00；VGA 640×480@60Hz（25 MHz 像素时钟，行 800 / 场 525 总时序）；检测结果黑白二值化（BLACK / WHITE）。

各模块职责速览：

sobel（顶层）

rtl/sobel.v · 顶层模块（TOP_LEVEL_ENTITY）

职责：例化全部功能模块并连接数据通路：uart_rx 收到的图片字节 → sobel_ctrl 检测边缘 → vga 显示 / uart_tx 回传；用 rst_n = sys_rst_n & locked 统一复位。

一句话解读：顶层不写任何算法，只做「组装」——看顶层代码就是看整机数据流。

clk_gen（PLL）

quartus_prj/ip_core/clk_gen/ · Quartus PLL IP

职责：50 MHz 晶振时钟 → c0 25 MHz（VGA 像素时钟）、c1 50 MHz（系统逻辑时钟）、locked 锁定指示。

一句话解读：VGA 显示和逻辑处理用不同频率的时钟，PLL 是 FPGA 里的「时钟工厂」。

uart_rx / uart_tx（串口收发）

rtl/uart_rx.v · rtl/uart_tx.v · 9600bps 参数化收发

职责：rx 把串行位流按波特率采样、拼成 8bit 字节（po_data + po_flag）；tx 反向把并行字节逐位发出。

一句话解读：串口是「慢速搬运工」——一帧 10 位（起始+8 数据+停止），是图像数据的入口和出口。

sobel_ctrl（Sobel 边缘检测）

rtl/sobel_ctrl.v · 本工程核心算法模块

职责：两个 FIFO 构成两行缓存，与当前行组成 3×3 窗口；计算 Gx / Gy → Gxy = |Gx|+|Gy| → 与 THRESHOLD 比较，输出黑/白二值图像。

一句话解读：图像卷积在 FPGA 上的标准套路——「行缓存 + 滑动窗口 + 乘加」，在框图里点它可下钻看流水线。

vga_ctrl（VGA 时序控制）

rtl/vga/vga_ctrl.v · 行/场同步生成

职责：按 VGA 640×480@60Hz 时序产生 hsync / vsync、有效区坐标 pix_x / pix_y，并把像素数据随同步信号输出到 rgb。

一句话解读：两个计数器（行 800 拍、场 525 行）+ 比较器就是 VGA 时序的全部秘密。

vga_pic（图像数据生成）

rtl/vga/vga_pic.v · RAM 读回 + 彩条背景

职责：sobel 结果按 pi_flag 写入双时钟 RAM；显示时在图片区域（640×480 中央 98×98）读 RAM 输出，其余区域输出 10 段彩条背景。

一句话解读：写时钟 50M、读时钟 25M 的「异步双时钟 RAM」是跨时钟域传数据的常用 IP。

⑤ 关键代码解读

1. 顶层组装：rst_n = sys_rst_n & locked

assign  rst_n = (sys_rst_n & locked);   // PLL 锁定后才释放复位
clk_gen  clk_gen_inst (.inclk0(sys_clk), .c0(vga_clk), .c1(clk_50m), .locked(locked));
uart_rx  uart_rx_inst  (.sys_clk(clk_50m), .rx(rx), .po_data(pi_data), .po_flag(pi_flag));
sobel_ctrl sobel_ctrl_inst (.pi_data(pi_data), .pi_flag(pi_flag), .po_data(po_data), .po_flag(po_flag));
vga      vga_inst      (.vga_clk(vga_clk), .sys_clk(clk_50m), .pi_data(po_data), .hsync(hsync), .vsync(vsync), .rgb(rgb));
uart_tx  uart_tx_inst  (.sys_clk(clk_50m), .pi_data(po_data), .pi_flag(po_flag), .tx(tx));

顶层就是「数据流地图」：rx → uart_rx → sobel_ctrl → vga / uart_tx。注意 rst_n 把 locked 与按键复位相与——PLL 未锁定时各模块保持复位，这是所有 PLL 工程的标配做法。

2. uart_rx：双级寄存器同步消亚稳态

always@(posedge sys_clk or negedge sys_rst_n)
    if(sys_rst_n == 1'b0) begin
        rx_reg1 <= 1'b1;  rx_reg2 <= 1'b1;  rx_reg3 <= 1'b1;
    end else begin
        rx_reg1 <= rx;    rx_reg2 <= rx_reg1;  rx_reg3 <= rx_reg2;
    end
assign start_nedge = rx_reg3 && (~rx_reg2);   // 检测起始位下降沿

串口线相对系统时钟是异步信号，第一级寄存器可能采到亚稳态，所以先用两级寄存器同步；再通过 rx_reg3 && ~rx_reg2 检测起始位下降沿，之后按波特率计数器在每位中点采样，拼出 8bit 数据。

3. sobel_ctrl：行/场计数与 FIFO 写读使能

if((cnt_v == 8'd0) && (pi_flag == 1'b1))  wr_en1 <= 1'b1;   // 第0行写入fifo1
if((cnt_v >= 8'd1) && (cnt_v <= 98) && (pi_flag == 1'b1))  wr_en2 <= 1'b1;  // 第1..98行写入fifo2
if((pi_flag == 1'b1) && (cnt_v >= 8'd2) && (cnt_v <= 99))  rd_en <= 1'b1;    // 第2行起开始读出

图像逐行到达：第 0 行进 fifo1，第 1 行起进 fifo2，第 2 行起边写边读——于是任意时刻 fifo1 存「上一行」、fifo2 存「上上行」，加上当前行正好凑齐 3 行。行缓存深度 = 行长度 100。

4. 3×3 窗口：三路数据拼成 a1..c3

a1 <= data_out1_dly;  b1 <= data_out2_dly;  c1 <= pi_data_dly;   // 第1列
a2 <= a1;  b2 <= b1;  c2 <= c1;                                   // 右移
a3 <= a2;  b3 <= b2;  c3 <= c2;                                   // 第3列

三行数据各经一拍延迟对齐后，用 9 个寄存器构成 3×3 滑动窗口：a 行 = 上上行、b 行 = 上行、c 行 = 当前行，每个时钟右移一列。这就是图像卷积在 FPGA 里的标准实现。

5. Gx / Gy 与 Gxy = |Gx| + |Gy|

gx <= a3 - a1 + ((b3 - b1) << 1) + c3 - c1;      // Sobel 水平核
gy <= a1 - c1 + ((a2 - c2) << 1) + a3 - c3;      // Sobel 垂直核
// gxy 按 gx/gy 符号分四路，等价于 |gx| + |gy|

Sobel 算子 = 3×3 卷积核（水平 [-1 0 1; -2 0 2; -1 0 1]、垂直转置）。代码里用 gx[8] 判断正负、按补码取绝对值相加，避免减法器处理负数——省资源的小技巧。

6. 阈值二值化与 VGA 行时序

if((gxy >= THRESHOLD) && (compare_flag == 1'b1)) po_data <= BLACK;   // 8'b0000_0000
else if(compare_flag == 1'b1)                    po_data <= WHITE;   // 8'b1111_1111
// vga_ctrl：hsync = (cnt_h <= 95) ? 1 : 0;  cnt_h 从 0 计到 799（H_TOTAL=800）

梯度幅值 ≥ 阈值判为边缘（黑色），否则白色——这就是「边缘检测 → 二值化」。VGA 侧同理：行计数器 0..799、场计数器 0..524，前 96 拍 hsync 拉低（同步脉冲），其余按 后沿/显示区/前沿 划分，在有效区内按坐标输出像素。
